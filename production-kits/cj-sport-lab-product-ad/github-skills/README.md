# GitHub Skills

This folder keeps the downloaded skill manifest and evaluation notes for the
CJ Sport Lab production workflow.

The full third-party repositories are intentionally not committed here. For this
project, the useful part is the operating record:

- which skill repositories were reviewed
- how many skill files they contain
- what each repository is useful for
- whether it should be installed, referenced, or skipped

Use `downloaded-skills-manifest.csv` together with
`docs/github-skills-evaluation.md` before installing any third-party skill into
the global Codex skills folder.
