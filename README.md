# AI Learning Notes

This repository is used as a personal working library for AI-assisted learning,
brand experiments, product content, and social-media production assets.

## Current Projects

- `campaigns/cj-sportlab/`  
  CJ Sport / CJ Sport Lab campaign package, including product images, portfolio
  pages, social post drafts, captions, and exported previews.

- `production-kits/cj-sport-lab-product-ad/`  
  A production kit for the CJ Sport Lab short-form product ad workflow. It
  includes brand logos, clean product images, stock video assets, thumbnails,
  storyboards, product generation prompts, license notes, and GitHub skill
  evaluation files.

## Usage Notes

- Product images are AI-generated concept assets.
- Stock video files are kept with source and license records in the production
  kit manifest.
- Third-party GitHub skill repositories are not vendored into this repo. Keep
  manifests and evaluation notes here, then install or update the original
  repositories separately when needed.
