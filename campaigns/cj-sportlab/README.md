# CJ Sport 试水作品包

这是一个用于作品集和社媒账号试水的模拟品牌内容包。品牌口径为：

- `CJ`：母品牌。
- `CJ Sport`：运动产品线。
- `Grip Trainer Kit`：第一轮低成本样品测试产品。

## 入口

- `index.html`：作品包总览页，已嵌入视频预览。
- `post-01.html`：TikTok Shop 风格选品图文。
- `post-02.html`：Amazon Listing 风格卖点图文。
- `post-03.html`：1688/TikTok/Amazon 选品复盘图文。
- `video-preview/index.html`：20 秒竖屏动态预览页，包含产品展示和人物使用场景。
- `exports/video-15s/cj-sport-15s-portfolio-sample.mp4`：15 秒 9:16 MP4 成片样例，用于作品集和面试展示。
- `ai-video-production-pack.md`：可灵 / Runway / CapCut 的 AI 视频生产包。
- `ai-video-shotlist.csv`：AI 视频分镜、提示词摘要、剪辑备注和质检表。
- `captions.md`：英文 caption 和 hashtags。
- `portfolio-case.md`：作品集案例说明。
- `creator-ads-case.md`：达人建联与 Meta 广告模拟增长案例。
- `creator-shortlist-sample.csv`：KOL/KOC 达人筛选样例表。
- `meta-ads-test-plan.csv`：Meta/IG/FB 广告测试假设表。
- `assets/images/hero-product.png`：AI 生成产品主视觉，当前通过裁切和覆盖标签做 CJ Sport 展示。

## 使用边界

- 这是模拟品牌资产，不是真实上架商品。
- 可以用于作品集展示、账号冷启动内容和面试说明。
- 不要直接写医疗、康复、治疗、疼痛缓解或保证效果类宣传。
- 1688 低价只作为找样品和询价方向，不写成已经成交的真实成本。
- 达人和广告案例属于模拟练习，不写成真实达人合作或真实广告投放结果。
